Official sign-in logos for the Log in / Sign up buttons.

Save each provider's official logo here, named exactly:
    google.svg    (or google.png)
    linkedin.svg  (or linkedin.png)
    github.svg    (or github.png)

A button shows its logo as soon as the file is here; until then it shows text only.
Use the artwork each company publishes for sign-in buttons, unaltered:
  Google   - developers.google.com/identity/branding-guidelines (the standard-colour "G")
  LinkedIn - brand.linkedin.com (the "in" bug logo)
  GitHub   - github.com/logos (the mark, black)
